I'm a Senior Software Engineer with 7+ years of experience building Java microservices and event-driven systems with Spring Boot, Spring WebFlux, Apache Kafka and AWS.

I like owning a service end to end: the API contract, the service boundaries, the data model and the rollout. I build systems that stay up when something downstream doesn't, using circuit breakers, retries with backoff, partitioned consumers and async workflows that isolate failures.
